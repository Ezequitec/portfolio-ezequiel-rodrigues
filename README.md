# 🚀 Portfólio Profissional — Ezequiel Rodrigues

Aplicação web desenvolvida com **Next.js, React, TypeScript e Tailwind CSS** para apresentar cases reais de automação, inteligência operacional, análise de dados e soluções aplicadas em ambiente logístico de alta escala.

🔗 **Acesse o Portfólio Online:** [Clique aqui para visualizar na Vercel](COLE_AQUI_O_SEU_LINK_DA_VERCEL)

---

### 📌 Cases Apresentados no Portfólio
* **Automação de Fluxos e Relatórios Operacionais:** Pipelines integrados via Webhooks e Google Apps Script para eliminação de tarefas manuais repetitivas.
* **Sistemas Internos de Qualidade e Auditoria:** Ferramentas web deployadas em produção para controle de processos, filas de treinamento e correção cadastral.
* **Inteligência de Dados & BI:** Dashboards interativos e cruzamento de indicadores operacionais para tomada de decisão em tempo real.
*(Todos os cases foram estruturados preservando a confidencialidade de dados corporativos).*

---

### 🛠️ Stack Utilizada
* **Frontend & Framework:** Next.js, React, TypeScript, Tailwind CSS
* **Deploy & Hospedagem:** Vercel
